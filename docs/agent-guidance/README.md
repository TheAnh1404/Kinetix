# Bản thay thế hướng dẫn agent

Các file trong thư mục này là nội dung thay thế đã chuẩn bị cho `.agents/rules/` và skill Kinetix. Môi trường hiện chỉ cho đọc `.agents`, nên các file gốc chưa được sửa. Không dùng file gốc để suy ra Family L1, yield, miễn gas hoặc giao diện theo tuổi là yêu cầu sản phẩm hiện tại. [AGENTS.md](../../AGENTS.md) đã được cập nhật để dẫn đến chuẩn mới.

| Bản chuẩn bị | File đích khi có quyền ghi |
| --- | --- |
| [kinetix-core.md](kinetix-core.md) | `.agents/rules/kinetix-core.md` |
| [frontend-web3.md](frontend-web3.md) | `.agents/rules/frontend-web3.md` |

| [kinetix-builder.SKILL.md](kinetix-builder.SKILL.md) | `.agents/skills/kinetix-builder/SKILL.md` |

Các link trong từng bản thay thế được viết theo vị trí file đích; thư mục này là bản chờ áp dụng, không phải skill đã cài. Không tự ghi đè thư viện skill thiết kế tổng quát. Khi áp dụng, kiểm tra diff và giữ frontmatter cho công cụ đọc rule/skill.
