They may contain superseded counts, assumptions, or deployment instructions. Use the current references above for supported behavior; an old plan is not evidence of a running deployment. The UniHack documents are historical hackathon material, not current product commitments or verified market research.

`.docs/` is retained to preserve existing handover links. `.agents/` contains local development skills and automation guidance; `AGENTS.md` contains repository-wide contributor instructions. They serve different purposes and are not duplicate product documentation. Historical skill examples are not current security or deployment specifications.
